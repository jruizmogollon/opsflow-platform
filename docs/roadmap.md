# Roadmap

## Release 0.1 - API foundation

- Create the solution and project structure.
- Add health check and OpenAPI documentation.
- Model organizations, users, roles, tickets and assets.
- Add database migrations and sample data.

## Release 0.2 - Ticket workflow

- Create and list tickets.
- Assign a technician.
- Change status and priority.
- Record comments and work notes.
- Store an audit trail.

## Release 0.3 - Clients

- Build the supervisor dashboard with React.
- Build the technician app with Flutter.
- Add authentication and role-based navigation.

## Release 0.4 - Portfolio quality

- Add automated tests.
- Add a clear setup guide.
- Add architecture diagrams and decisions.
- Add screenshots and a short demo.
- Review secrets and publish only safe sample configuration.
